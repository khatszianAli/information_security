# information Security
This repository contains laboratory works and projects for the course Information security.  

This course provides foundational knowledge in Information Security. Topics include core concepts such as terminal, confidentiality, integrity, and availability, risk management, types of cyber threats, basics of cryptography, network security, and secure programming practices. Students will gain practical skills in identifying vulnerabilities, implementing basic security measures, and understanding the ethical and legal aspects of cybersecurity.

 # Learning Outcomes
- Understand terminal shell and main instructions
- Understand the fundamental principles of information security, including the CIA triad (Confidentiality, Integrity, Availability).
- Identify and classify various types of cyber threats and vulnerabilities.
- Apply basic cryptographic techniques to secure information.
- Evaluate and implement security measures to protect networks and systems.
- Develop secure programming practices to mitigate risks in applications.
- Conduct risk assessments and propose strategies for effective risk management.
- Analyze ethical and legal aspects in information security scenarios.
- Effectively explain security concepts to diverse audiences.
- Work collaboratively in teams, demonstrating cohesion and effective interaction in group projects.
